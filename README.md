# pokemon-gen1-analysis-project

**Tool used:** MySQL / MySQL Workbench 

## SQL Techniques
- ELT Views (`CREATE OR REPLACE VIEW`) 
- Data Cleaning & Normalization (`LOWER`, `TRIM`, `REPLACE`, `CASE`) 
- Feature Engineering (BMI calculation, weight class binning) 
- Advanced Analytics (CTEs, Window Functions: `RANK() OVER`)

## Project Structure
This project contains the complete script from initial raw data checks and ELT view creation to all 5 exploratory data analysis queries using pokemon gen 1 dataset. 

## Key Highlights
- **Data Cleaning:** Neutralized character encoding bugs and standardized missing secondary types and classified as 'NONE' and 'single type' categories.
- **Feature Engineering:** Created custom dimensions like weight_class (featherweight, midweight, heavyweight) and calculated a metric bmi index. 
- **Insights:** Explored type physical averages, weight distributions, extreme BMI outliers, and used window functions to find the tallest Pokémon per primary type.

> **Note:** This project used synthetic data generated by AI tool and used for brainstorming queries.
